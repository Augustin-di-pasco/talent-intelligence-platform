# ZERILYS — Beyond the CV.

Talent Intelligence Platform.

This repository contains the deployment package for ZERILYS. The source archive is kept in this private repository and unpacked during the Render build.

## Deployment
Render Blueprint: `render.yaml`
The public service starts with candidate/company registration disabled. Do not enable registration until legal, security, moderation and backup checks are complete.

## Release
